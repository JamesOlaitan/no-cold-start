# 60-second demo script

**0:00–0:10 — the problem, fast.**
"Every AI agent starts from nothing. We built one that doesn't — and more than that, it can tell you *why* it remembered what it remembered."

**0:10–0:30 — the live moment.**
Type "Frank." Whisper plays out loud, stopwatch visibly under 1 second.
Say while it plays: "That's not a database dump — it's the two facts that scored highest right now, out of everything we know about Frank, picked by an aggregation pipeline running live against MongoDB Atlas."

**0:30–0:45 — the differentiator.**
Click "Why did you say that?"
"Most memory systems only store facts. We also store *decisions* — the actual choice the system made, the facts it rejected, and why. This is a real MongoDB document, not a log line — you can query it, chain it, walk it backward with `$graphLookup`."

**0:45–0:55 — the capstone.**
"And it's not just about Frank. We logged decisions about our *own* build choices the same way — ask the system why it picked MongoDB over a vector database, or ElevenLabs Flash over the standard model, and it answers from a Decision document our own team wrote, in the same collection."

**0:55–1:00 — close.**
"No cold start — for the people you know, and for the system explaining itself."

## Notes for whoever's recording
- Have the tab already open and the name box empty before hitting record — don't waste seconds loading the page on camera.
- Say the person's name confidently once ("Frank") so you don't need a retake.
- If the audio autoplay is blocked by the browser, click once on the page first before typing the name.
